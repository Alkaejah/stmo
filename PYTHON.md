# Steps to setup separate python environment inside the project

## 1. Create a folder📂 in apps/api/src directory (name of your choice)

## 2. Place the requirements.txt📄 , assignment_updater.py🔄, runner.py🚀, and the model.joblib📑 in your created folder📂 in apps/api/src directory

## 3. Run this 👉 python -m venv venv 👈 command in the terminal to create python environment

## 4. Add this 👉 venv/ 👈 line inside the .gitignore🚫 file located in the root of the project

## 5. Run this 👉 venv\Scripts\activate 👈 command in the terminal to activate the python environment

## 6. Run this 👉 pip install -r apps/api/src/your-folder-name-created/requirements.txt 👈 command in the terminal to install all libraries needed
